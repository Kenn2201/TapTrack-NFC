# Card Lifecycle

## States

```
UNASSIGNED → ACTIVE → LOST
                    → REVOKED
                    → REPLACED
                    → DISABLED
```

## Rules

- Never delete issued cards
- Revocation preserves audit history
- Replacement creates a new card and links to the old one
- Attendance history stays with the USER, not the card
- Cards store only opaque hashed credentials

## Physical Card Content

```
URL: https://nfc.kenncode.me/t#<opaque-random-token>
```

- Token generated by `crypto.randomBytes(24).toString('base64url')`
- Database stores `SHA-256(rawToken)`
- Raw token shown only during provisioning
